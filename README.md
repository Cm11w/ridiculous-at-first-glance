# Ridiculous at First Glance, Real by the Second

One sentence, at most 200 characters, pitching a startup idea so strange it
sounds like a joke — until you see the customers and the money.

## The pitch

> We rent trained ferrets to pull cables through walls for electricians, who pay per job, because a ferret squeezes where no drill can reach and works for chicken treats.

Why it holds together: electricians constantly need cables fished through
cavities no drill or fish tape can reach, and they already pay per job for
specialist help. A trained ferret does the run in minutes, costs almost
nothing to keep, and works for chicken treats — so the absurd premise is a
real, billable service with obvious customers and an obvious price.

## How it works

`main.ts` writes the pitch above, verbatim, to `/output/entry.txt`. It uses
only Node's standard library, needs no network, and is fully deterministic:
every run writes the exact same bytes.

## Run

```sh
node main.ts
cat /output/entry.txt
```
